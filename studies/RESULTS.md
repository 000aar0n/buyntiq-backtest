# Preliminary ranking study — 2026-10-09

**No production promotion.** The shared ensemble did not beat the simple momentum baseline in this first experiment.

Real preserved Yahoo daily OHLC/adjusted-close/volume/splits and SEC companyfacts responses were used. No synthetic prices or current market-cap substitutions were used. The available cache covers 722 current technology listings, not the full US universe, and ends on 2026-10-06. The test begins 2021-10-08, holds 15 stocks and rebalances quarterly, with $2B historical estimated cap, $5 nominal price, $10M liquidity and 10bps per trade. Unknown enabled-filter inputs were excluded. Missing cached SEC facts reduce coverage. Current listing membership introduces survivorship bias.

| Strategy | Ending $100,000 | Return from starting cash | Maximum drawdown | Trading costs |
|---|---:|---:|---:|---:|
| 12–1 month momentum | $267,149 | +167.15% | −36.15% | $4,937 |
| Shared ML with momentum fallback | $223,498 | +123.50% | −35.18% | $4,587 |

SPY's matching close-to-close return was +90.24%. Portfolio returns above include first-day opening execution and costs; the app's matching-period edge uses first close instead. The ensemble passed its historical ranking gate on 10 of 20 rebalance dates. These are **preliminary technology-subset results**, not proof of full-US outperformance or future investment returns.

The actual full-US website run loaded 5,583 stock histories, then stopped on an SEC HTTP 403. It produced no performance result. A provider preflight and a dated official SEC ticker-directory fallback were added so a directory outage can be handled and a blocked share-count API is detected before the expensive download. Historical capitalization checks are never silently disabled.

Reproduce the preserved-data experiment with `python studies/run_cached.py RAW_DIRECTORY OUTPUT_DIRECTORY momentum pooled`. The raw provider responses are external inputs, not generated by that script.
